# @anthonycmartin/bicep-testing

The independent, non-official Node library for asserting on Bicep templates without deploying to Azure.

See the [repository README](https://github.com/anthony-c-martin/bicep-test#readme) for installation and usage, and the [Node development guide](https://github.com/anthony-c-martin/bicep-test/blob/main/docs/node.md) for contributor instructions.
