Capabilities

Local snapshots and live deployment tests

01

Evaluate a snapshot locally

Compile a .bicepparam entry point and return the predicted resources, resolved outputs, and compiler diagnostics for assertions.

  • No Azure subscription
  • No credentials
  • No deployed resources
02

Run an Azure deployment test

Create a Deployment Stack when a test needs to inspect deployed resources, service responses, or other runtime behavior.

  • Normalized deployment outputs
  • Managed resource inventory
  • Deterministic teardown

Library behavior

What the libraries handle

01

Native test frameworks

Use Jest, MSTest, Go testing, Pester, or pytest without introducing another test runner.

02

Bicep CLI lifecycle

A session downloads or reuses a requested CLI version, owns its process, and closes it through the language's standard cleanup pattern.

03

Shared test input

The same .bicepparam entry point can be used for local snapshots and opt-in deployment tests.

04

Deployment cleanup

Live test results own the Deployment Stack and provide idempotent teardown for the stack and its managed resources.
